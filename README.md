## 경로와 유지 관리

분류는 이 저장소의 games/, tools/, projects/에서 관리한다. 개별 저장소의 이름, 배포 주소, 이력은 유지한다. 배포되지 않은 저장소는 저장소 링크만 제공한다.

포트폴리오 원본은 tools/portfolio/, 이력서 원본은 tools/resume/index.html이다. 이전 portfolio/와 JUBO_RESUME_2026_V3.html은 새 경로로 이동시키며 쿼리와 작품 번호 해시를 보존한다. 이후 수정은 새 경로에서 한다. 기존 portfolio/assets 등 호환 파일은 기존 링크를 위해 유지한다.
