# 사장님, 사장님!
김주보의 경영 시뮬레이션 기획서를 바탕으로 만든 1인용 브라우저 게임.

## 실행
`index.html`을 열거나 정적 서버에서 제공한다. 빌드·API 키·서버가 필요 없다. 글꼴 로딩 실패 시 시스템 글꼴로 표시한다.

## 게임
빵집으로 시작해 연구, 직원 교육·배치, 가게 인수·합병·매각을 통해 성장한다. 영업 1회는 한 분기이며 8종 미니게임 중 하나를 선택하거나 성과 50%로 자동 진행한다. 급여·재료비·관리비·대출 이자를 결산한다. 레벨 5, 순자산 2억원, 평판 65에서 상장 가능. 최종 목표는 순자산 10억원이며 달성 후에도 계속 플레이할 수 있다.

모든 금액의 내부 단위는 만원. 예금 1%, 대출 3%는 분기 이율이며 현실 금융과 무관한 게임 수치다. 본점은 매각 불가. 위기 시 예금·대출을 먼저 사용하고 회생 지원을 받을 수 있다.

## 저장
동일 브라우저의 localStorage에 자동 저장. 설정에서 JSON 파일로 내보내거나 다른 기기에서 가져올 수 있다. 서버 저장과 계정 연동은 없다.

## 미니게임
배달(20초), 진열(12초), 철거(20초), AI 모의 훈련(20초), 회계(30초), 오타 찾기(시간제한 없음), 도난 감시(20초), 고객 응대(20초). 터치·마우스 지원. 배달 방향키, 진열 스페이스 지원. 배달 자이로와 3D 큐브는 웹판에서 터치·색상 퍼즐로 단순화했다. 실제 AI 학습·캡챠 서비스로 데이터를 보내지 않는다. 고객 불만은 기획서의 중복된 도난 설명 대신 응대 선택지로 재구성했다.

## 구현 범위
정적 GitHub Pages용 첫 버전. 실시간 온라인, 도시 연동, 실거래·결제, 광고, 계정·랭킹 서버, 100명 이상의 인재, 음원·성우·자이로 등은 포함하지 않는다. 모든 캐릭터와 배경은 자체 SVG/CSS로 구성했다. 기존 작품의 음악이나 캐릭터를 사용하지 않는다.

## 검증
`node test.cjs` / `node --check game.js` / `node --check engine.js`
경제 모델, 페이지 렌더 함수, 채용·연구·금융, 8종 게임 초기화/결산, 상장과 증자 중복 방지를 검증한다. DOM 모의 환경 검사이며 실제 브라우저의 시각·터치·프레임 검사를 대체하지 않는다.
